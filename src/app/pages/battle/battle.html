} info Why Polling Instead of WebSocket?

Polling is used here instead of GraphQL Subscriptions/WebSockets for the following reasons:

  1. The mock JSON-GraphQL server (json-graphql-server) does not support real-time WebSocket connections or GraphQL Subscriptions
  2. Polling (via RxJS interval(5000).pipe(switchMap())) simulates real-time behavior for demonstration purposes
  3. This approach maintains compatibility with the project's specified requirements while providing similar functionality
  4. In a production environment with Apollo Server or similar, this would be replaced with proper GraphQL Subscriptions over WebSocket for true real-time updates
